# Digital Governance & Gulf Technology Observatory

Independent bilingual research and educational static site. Version v1.0.0 first prepared for publication 2026-07-01T00:00:30Z UTC.

The site is designed for GitHub Pages under `/digital-governance-observatory/`, not only from the domain root. It uses static HTML, CSS, a small inline theme toggle, no database, no cookies, no paid services, and no invasive analytics.

## Local checks

```bash
npm run build
npm run test:links
npm run test:content
npm run review:final
```
